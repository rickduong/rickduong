# Bikes and Gear

A simple archive of bike builds, gear, components, and lessons learned from the road.

## Possible topics

- current bike setup
- maintenance notes
- equipment reviews
- upgrades and experiments
- what works well for specific terrain

## Suggested format

- summary
- setup details
- what is working
- what is next
- practical notes for future reference

## Add a gear note

Use a naming convention like:

```text
YYYY-MM-DD-bike-setup.md
```
