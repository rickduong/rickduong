# Photo assets

Add the full-size images to this folder with these filenames:

- `north-cascades.jpg`
- `ramrod.jpg`
- `stp.jpg`
- `flying-wheels.jpg`
- `redmond-club.jpg`
- `mount-baker.jpg`

The mosaic automatically creates smaller cropped thumbnails with CSS. Selecting any tile opens `photo.html` with the larger photo and description. If your images have different names or extensions, update the matching paths in `index.html` and `photo.js`.
