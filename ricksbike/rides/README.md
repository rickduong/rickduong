# Ride Reports

A collection of ride reports, short essays, and field notes from the road.

## Format

Each ride entry should include:

- a title and date
- ride type or event name
- distance and elevation
- a short reflection
- a few representative photos
- a takeaway or lesson

## Example entries

- [Template: Ride report](./_template.md)

## Add a new entry

Create a file using the naming convention:

```text
YYYY-MM-DD-ride-name.md
```

For example:

```text
2026-09-18-ramrod.md
```
