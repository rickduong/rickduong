# Route Notes

A place for favorite roads, loops, climbs, and places worth revisiting.

## What belongs here

- favorite climbs
- recurring loops
- scenic roads
- training routes
- route recommendations with context

## Suggested format

- route name
- area and terrain
- distance and elevation
- why it matters
- best time to ride
- caution notes

## Add a route

Use a file naming convention like:

```text
YYYY-MM-DD-route-name.md
```

or a more evergreen naming style:

```text
mount-rainier-climbs.md
north-bend-loop.md
```
